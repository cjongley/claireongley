# Claire — profile site
 
A small, single-page profile site: a mix of work and personal, with a generative "Bargello wave" pattern as the signature visual — click "Shuffle the pattern" to regenerate it. 

## About this site
 
One scrolling page, four sections:
 
- **Hero** — name and a one-line intro.
- **Work** — what you do at Inner West Council: Copilot Studio agents,
  documentation, training the people who use them.
- **Making** — the Blue Lily Bargello quilt project, board games,
  gaming.
- **Say hi** — email, GitHub, LinkedIn.

 
## Files
 
- `index.html` — page content and structure
- `style.css` — colours, type, layout
- `script.js` — draws the wave dividers
