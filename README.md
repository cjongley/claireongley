# Claire — profile site
 
A small, single-page profile site: a mix of work (AI agents at Inner West
Council) and personal (Bargello quilting, board games, gaming), with a
generative "Bargello wave" pattern as the signature visual — click
"Shuffle the pattern" to regenerate it.
 
Note: this README documents the repo for your own reference — it
won't show up on the published site itself, only on the GitHub repo
page.
 
## About this site
 
One scrolling page, four sections:
 
- **Hero** — name and a one-line intro.
- **Work** — what you do at Inner West Council: Copilot Studio agents,
  documentation, training the people who use them.
- **Making** — the Blue Lily Bargello quilt project, board games,
  gaming.
- **Say hi** — email, GitHub, LinkedIn.
The wavy dividers between sections aren't just decoration — they're
generated the way real Bargello quilting works: strips of colour
whose edges follow the same wave, each strip's phase staggered so
they interlock into a flame pattern. The "Shuffle the pattern" button
at the bottom regenerates them with a new random wave, colour order
included.
 
## Files
 
- `index.html` — page content and structure
- `style.css` — colours, type, layout
- `script.js` — draws the wave dividers
